Coverage: work integrated during **10–24 November 2026**, including the source deliveries prepared on 9 November and merged during that period. Only changes reachable from the tested release application are included. Some improvements had already shipped in 2026.46.1/2026.46.2; they are retained here to cover the complete two-week work summary rather than presented as all new in 2026.48.1.

Released application: `b696ab86bd1c128729a079b68c0082e6df3d36a5`. This document is a later documentation update; it does not change the release tag or installers.

Entries describe delivered behavior within its documented scope. A feature or partial fix is not a claim that its broad parent issue is fully resolved. Earlier failed tests and accepted limitations remain recorded. No universal speed-up percentage or general memory-use improvement is claimed.

## Detailed fixes and improvements included since 2026.46.2


### Performance and built-in file conversion

- **Less background work in large Writer documents:** language-status updates now coalesce repeated whole-document reads while text is changing and reuse already available content (#327, PR #349).
- **Built-in desktop conversion:** the required private conversion runtime is included with the desktop apps, so no separate conversion program or environment-variable setup is needed (#30, #317). Browser-only format limitations remain documented.

### Writer

- Open EPUB books as editable DOCX copies, preserving the tested reading order, lists, tables and images; UTF-8 and UTF-16 XML inputs are supported (#356).
- Correct native macOS page presentation for documents that could appear blank (#359).
- Make Command+Up and Command+Down navigate to document boundaries on macOS (#358, PR #360).
- Restore document input focus after inserting table columns (#361).
- Keep stacked ribbon controls and focus outlines visible, including collapsed ribbon groups (#362).
- Keep keyboard focus indication visible after navigating the ribbon with the mouse (#369).
- Use the existing translated style-management labels and hints (#363).
- Preserve separate Undo/Redo histories in Linux Find/Replace inputs and document editing (#368).
- Correct uppercase DOCVARIABLE title measurement, character spacing and horizontal scaling while preserving the original fields and cached content (#374).
- Restart numbering at the newly selected list level rather than the previous level (#46).
- Correct AutoFit cases where a wide column and a minimum-width column made the table wider than the page (#48).
- Update complete compound page-number labels in the table of contents, including labels split across text runs (#50).
- Keep the opposite crop edge unchanged when an image-crop handle reaches its boundary; corner handles are constrained independently (#49).

### Spreadsheet and file compatibility

- Paste only the selected first HTML table, avoiding extra cells and numbers from following tables or HTML comments (#20).
- Offer XLSX Save As for imported XLSB files instead of unsupported XLSB overwrite. Cancelling preserves the original XLSB and the unsaved working copy (#377).
- Warn explicitly when a workbook requests unsupported iterative calculation; this does not add iterative formula evaluation (#59).
- Detect unsupported XML extensions beyond the main document body, including headers, styles, worksheets and slide masters, so compatibility reports include those parts (#40).

### Email and desktop reliability

- Save a locally composed email draft using Ctrl+S on Windows/Linux and Command+S on macOS, while keeping modal and document input isolated (#379).
- Correct the Windows runtime-unpacking compatibility problem (#372).
- Declare the Linux native-confirmation helper dependency and provide an explicit error when the helper is missing (#378).

## Known limitations and accepted risks

- In one earlier automated macOS Suite save preflight, an edit was visible and the document was dirty, but the requested Command+S did not update the private test file. Six later controlled copies and the regular same-package save/reopen cases succeeded. The original cause remains unknown; an intermittent product-save problem is not excluded. No driver or product fix is claimed for that observation.
- The page counter issue (#366) remains deferred. The separate UOP rectangle-fill runtime issue (#375), chord rendering (#380), theme-background and footer-date improvements remain outside this candidate.
- Native and format results are bounded to the documented cases. They do not certify every document variant, font substitution, pagination, embedded object or layout. Font substitutions and excluded source-format fidelity observations remain explicitly recorded.
- macOS testing uses ARM64 hosts; there is no Intel macOS package claim. Linux native tests use virtual X11/software graphics, and AppImage extraction/AppRun is verified separately from physical FUSE mounting. Some unavailable or clipped ribbon contexts are not certified.
- Email tests use synthetic local IMAP accounts and drafts. They do not certify delivery to live providers or SMTP sending. Database tests cover the documented synthetic SQLite read/query/export routes, not general Access-file write support.

The scope-specific source evidence linked from commits remains applicable. In particular, a successful build or signature alone does not certify native operation, all file variants, or full acceptance of a broad issue.
