## Byte and host isolation

One preparation job checks the own Linux job's success independently of other OS results, verifies the entire canonical `uitgave-Linux` ZIP SHA-256/size, then extracts only the twelve standalone DEB/AppImage files and their six Linux package reports. Office is never extracted. Original source tree, version, canonical archive/member, package/report hashes, bytes and app identities are preserved in each origin receipt. Before that download, a separately committed intake pins the official artifact ID/name/SHA/bytes, attempt 1, job time window and all required installer/runtime/native gates. A separate SHA-bound go marker starts the workflow. Source, intake, go marker and prior proof remain distinct.

The original package bytes are uploaded separately per app. Every fresh native test host downloads only its own app input ZIP, verifies that full ZIP against the Actions digest and producer QA/source/parent chain, then verifies its two package hashes and package report again. No suite ZIP, suite payload, shared suite profile, installed host LibreOffice or checkout runtime is exposed to those app hosts. The native executable must hash exactly to its inspected payload. HOME/XDG/PATH are isolated per package and the actual native identifier/version/name, own profile, process/resource paths and needed resources are recorded.

Maximum three app hosts operate concurrently. Each performs real native pointer/keyboard/file-picker operations on its actual standalone binary. Readonly DOM access uses the existing strict transport; compiled native metadata uses only the public readonly app metadata API. Functional cases do not inject files, state, model changes or backend calls. PID/starttime/ELF/XID/focus binding is reused from the proven native P2 protocol. Any driver repetition reuses the immutable per-app inputs via `reusePreparedRun` and selects only cases that require retesting; it must not redownload the full canonical ZIP. A failed global release or QA run does not invalidate independently verified own-platform/package/input evidence.
