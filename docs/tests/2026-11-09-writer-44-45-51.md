# Writer headers, styles and notes: issues #44, #45 and #51

This completion branch combines the earlier section-target repairs with native
document fields, four-kind style management, and ODT preservation. It includes
the separate first/even/default header target repair and following-style repair.
The section ODT module was coordinated with the owner of #55; there is one
conversion wrapper, with explicit ordering between the two metadata owners.

## Reproduction

```sh
pnpm exec tsc --noEmit
pnpm exec vite build --configLoader runner
pnpm exec vitest run --configLoader runner --maxWorkers 2
pnpm i18n:check
node scripts/test-tekst-kopvoetdoel-gui.mjs
node scripts/proef-writer-44-45-51.mjs
OPENAEC_CONVERSIE_PROGRAMMA=/trusted/path/to/soffice node scripts/proef-writer-odt.mjs
```

The GUI scripts need Playwright; `OOS_PLAYWRIGHT_MODULE` can point at an existing
installation. They serve the production build and exercise the pinned 0.5.1
Writer engine. React-fiber access is confined to the test scripts for saving and
independent native state inspection. No test helper is shipped in the app.

The real ODT test invokes **the production `formaten.converteer` wrapper**. Only
its IPC transport is replaced by the actual trusted LibreOffice executable. It
uses an isolated safe profile and disables default-printer discovery. This
verifies both wrapper ordering and the real conversion filter, rather than
testing only a standalone filter command.

## ODT interoperability

ODT remains a standard ODF package with its uncompressed `mimetype` entry first.
Visible document text, standard styles, note bodies and citations remain readable
in other ODF applications. A manifest-declared inert style library and bounded,
versioned Writer metadata retain semantics that the converter flattens, including
named list/table styles and section-specific automatic note settings. The style
library contains no original body/header/note text, macros or unrelated custom XML.

Synthetic bookmarks bind preserved properties to their corresponding paragraphs
and tables; they are removed on import. Existing document and note text is never
replayed from a snapshot. Changed external style definitions and changed custom
note labels remain authoritative. Table properties are restored only while the
corresponding shape/style assignments agree. Section geometry/header authorship
is restored only when content/styles hashes and section structure still agree.

Applications that remove the optional metadata still receive ordinary visible
ODF content, but cannot retain every Writer-specific named/scoped distinction.
This is not a claim of lossless conversion of arbitrary third-party ODF features.
LibreOffice's zero-based `text:start-value` filter convention is accommodated at
the conversion boundary; native DOCX numbering remains one-based. Newly created
endnotes explicitly request Roman numbering; an existing omitted OOXML `numFmt`
is read as the ISO decimal default, matching the pinned engine.

Package mutations retain the existing explicit reload/Undo-history warning.
Native field insertion and direct note editing keep native Undo/Redo. Existing
published installers are unchanged; this work belongs to the next release.
