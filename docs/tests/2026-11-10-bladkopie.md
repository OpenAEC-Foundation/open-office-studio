# Worksheet copy preserving owned parts (#61)

The production copy command used a dense cell/format copy followed by several
native operations. A before-change actual-core probe confirmed that its source
text shape and legacy note were both absent from the copied sheet (source/copy
counts: objects 1/0, notes 1/0). A sparse formatted cell at XFD1048576 also made
that algorithm unsuitable for a full worksheet copy.

The command now copies the saved worksheet and its reachable OPC parts before a
single editor replacement. Shared workbook resources (styles, shared strings,
theme, persons and pivot caches) remain shared. Owned drawings, media, charts,
tables, comments and their relationships get independent paths. External
relationships are retained without being opened. The streaming worksheet rewrite
does not materialize a cell grid or XML cell tree.

Self-qualified formulas, chart sources, validation/conditional-format formulas,
internal hyperlink locations and copied local names follow the new sheet name.
Other sheets, external workbooks, quoted formula strings, structured headings
and global names retain their meaning. Tables get workbook-unique IDs and names;
thread IDs and replies remain distinct while authors stay shared. Existing
local-name scopes and workbook view indices shift at the insertion position.
The obsolete calculation chain is removed and full recalculation requested.

The copy dialog displays the loss of undo history caused by reloading. It pins
the source sheet/version at opening, checks readonly/version again after saving,
and cancels pending work when closed. The existing move route remains native.
Workbook structure protection is checked before any replacement.

## Remaining scope

This is an in-workbook copy repair. Macro workbooks, PivotCharts, slicers,
timelines, linked controls and non-worksheet sheet types are explicitly refused
before replacement. Cross-workbook copy and simultaneous editing of grouped
sheets remain outstanding. Issue #61 stays open; this is not a claim that the
whole issue or general Excel interoperability is complete.
