# Open Office Studio 2026-W45.4

Published on 6 November 2026 with 28 installers for all seven applications:
[download 2026-W45.4](https://github.com/OpenAEC-Foundation/open-office-studio/releases/tag/v2026.45.4).
All 28 public installer links were checked without authentication. The
[installer verification report](../tests/2026-11-06-uitgave-2026-45-4.md)
records the actual packages, signatures, native Linux starts and save/reopen
results.

Spreadsheet now persists recalculated formula results when saving an edited
workbook. Previously the visible result could be correct while the saved XLSX
still contained a stale cached value. The independent formula matrix checks
the actual saved values as well as reopening and recalculation. See
[the spreadsheet verification report](../tests/2026-11-06-rekenbladmatrix.md)
and PR #176.

Writer now preserves character styles and direct formatting on footnote and
endnote references when rebuilding a document part after an unrelated edit.
References retain their enclosing revisions and hyperlinks. The document
matrix now uses the production corrections and checks reference formatting
independently. See [the document preservation report](../tests/2026-11-06-documentmatrix.md)
and PR #177 for the pinned original-adapter comparison and remaining limits.

The release also includes the standalone Office preview package merged in
PR #175, with its separate source and package verification. It is a reusable
viewer component; it does not add another desktop installer.

Available installers: Office, Writer, Spreadsheet, Presentation, Email,
Notition and Database, each with a signed Windows x64 EXE, a signed and
notarized macOS Apple Silicon DMG, and Linux x64 DEB/AppImage packages with
detached OpenPGP signatures. All build, signing and package checks passed;
58 checksum entries and 15 OpenPGP signatures were independently verified.
The parallel native UI migration in PR #116 is excluded.

Synthetic regression results do not establish lossless handling of arbitrary
Office documents. The full D2 landscape-page comparison is recorded in
PR #179. Live Y-app storage integration, the original application's complete
Ctrl+S chain and remaining broad note/PDF/ODF requirements stay open.
