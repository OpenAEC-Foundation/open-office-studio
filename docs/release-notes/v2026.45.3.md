# Open Office Studio 2026-W45.3

[Published downloads](https://github.com/OpenAEC-Foundation/open-office-studio/releases/tag/v2026.45.3): 28 installers for Office, Writer, Spreadsheet, Presentation, Email, Notition and Database. Each app has a signed Windows x64 EXE, signed/notarized macOS Apple Silicon DMG, and Linux x64 DEB/AppImage with detached OpenPGP signatures. Checksums and the public signing key are included.

This release combines the merged workbook name manager, workbook locale/number-format handling, bidirectional footnote/endnote conversion, and PDF links in notes, tables and repeated headers/footers. The six owner-approved Office, Writer, Spreadsheet, Presentation, Notition and Email logos are carried through their own app and package assets; Database retains its separate identity.

The logo sources and platform assets use one checked generation pipeline, including the existing Python entry point. Sources are unchanged 512px raster masters, not vector artwork. Windows installer and uninstaller icons are explicitly selected and checked against the actual PE resources, including the installed uninstaller after signing. Per-app favicons are selected during the HTML build and identifiers, profiles and file associations are preserved.

See the [published-package verification report and screenshots](../tests/2026-11-06-uitgave-2026-45-3.md). All 28 public installer URLs returned HTTP 200 with the expected file size, and the 60 uploaded assets have been checked. All seven Linux DEBs and seven AppImages have been started with separate test profiles; each running executable hash matches its own package. Issues #165–#170 are closed. Existing 2026-W45.1/45.2 downloads remain available. Broad ODT/note-editing/PDF-option requirements remain open; the parallel native UI migration #116 is excluded. The separate reusable-preview package in PR #175 is later work and is not included in these installers.
