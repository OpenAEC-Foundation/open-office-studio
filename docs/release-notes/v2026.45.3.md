# Open Office Studio 2026-W45.3 — release candidate

This candidate combines the merged workbook name manager, workbook locale/number-format handling, bidirectional footnote/endnote conversion, and PDF links in notes, tables and repeated headers/footers. The six owner-approved Office, Writer, Spreadsheet, Presentation, Notition and Email logos are carried through their own app and package assets; Database retains its separate identity.

The logo sources and platform assets use one checked generation pipeline, including the existing Python entry point. Sources are unchanged 512px raster masters, not vector artwork. Per-app favicons are selected during the HTML build and identifiers, profiles and file associations are preserved.

This candidate is not yet published. Normal Windows/macOS/Linux packaging, signing and installer checks must pass before publication. Existing 2026-W45.1/45.2 downloads remain available. Broad ODT/note-editing/PDF-option requirements remain open; the parallel native UI migration #116 is excluded.
